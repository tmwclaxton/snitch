# Platform covers (not official embeds)

Official Instagram/TikTok/Facebook iframes fight the print frames and rate-limit in grids. Do not load those players in product UI.

## Rules

- `PlatformEmbed` shows a durable still cover (`cover_url` from local `/storage/post-covers` or ytimg) via `SnitchImage` (paper placeholder + `@error`). Never put a signed CDN URL or an mp4 into an `<img>`. Compact proof sheets (Feed, Explore, Winners) are cover-only - do not pass `media_url` into them. Image `media_url` is only used on the post detail player when it is a durable still; local mp4 may play muted. Never load an Instagram/TikTok CDN reel as a grid preview. When no durable cover exists, show the paper `SnitchImage` fallback - not a grey "Preview unavailable" box. Avatars go through `SnitchAvatar` / `AvatarArchive`.
- Feed, Explore, Dashboard, Winners, and Snitch Show sheets stay covers. Do not put `<iframe>` players in those grids.
- The post page (`feed/Show`) is the exception: pass `interactive` so one official player loads in `.snitch-post-player` (wide enough to use, not the 3/4 polaroid crop). Instagram uses `/embed/` there so the carousel can be swiped. Keep the "Open on platform" control off that player. From the `lg` breakpoint the page is `.snitch-post-fit`: a compact two-column layout with the player on the left (4/5, or 9/16 for TikTok, YouTube, and Facebook), the caption under that player and its metrics, and the analysis notes on the right. Cap the player height with `svh`, but do not lock the page to the viewport or put scrollbars on the caption or notes. The page itself scrolls when the write-up is long. Do not put a fixed 52rem frame back on that player. Instagram frames need an intrinsic `aspect-ratio: 4 / 5` (same idea as TikTok's 9/16) so they are not wiped by the shared `height: 100%` rule on an auto-height parent - that collapse shows up as `ERR`-free but tiny (~150px) players.
- `Post` appends `cover_url`. Prefer the stored `posts.cover_url` column, then payload stills (displayUrl, TikTok `video.cover.url_list`, originCover, Facebook `media.0.thumbnail`), then YouTube `hqdefault`. Never prefer a video file over a still.
- Instagram, TikTok, and Facebook CDN stills are signed and expire (Instagram `oe`, TikTok `x-expires`). `PostCoverHydrator` downloads those bytes to `storage/app/public/post-covers/{id}` and stores `/storage/post-covers/{id}.jpg` plus `cover_source_url`. YouTube `i.ytimg.com` stays a remote URL. Do not keep a signed CDN URL once the file is on disk. Avatars mirror to `storage/app/public/avatars/{social_id}-{hash}.{ext}` via `AvatarArchive` / `snitch:mirror-images`.
- LinkedIn video payloads have no thumbnail. `video.stream_url` on `dms.licdn.com` has no file extension, so it must not be stored as `cover_url`. When no still exists, grab one JPEG frame with ffmpeg into `post-covers/{id}.jpg`. The grid accessor ignores a stored cover that is not an image.
- If the signed still 403s, `--fetch` (and sync) recovers a fresh image without Firecrawl: Instagram TikHub `get_post_info_by_code` (then `/{p|reel}/{code}/media/?size=l`), Facebook page `og:image`, TikTok TikHub `one_video` (then oEmbed). Do not Firecrawl every post for og:image. Never leave an expired CDN URL in `posts.cover_url` - keep it only in `cover_source_url` until a durable local (or ytimg) file exists.
- Backfill with `php artisan snitch:mirror-images --explore --fetch` for the Explore catalogue (completed reel-like posts, including untracked / soft-deleted memberships), or `snitch:mirror-images --posts --avatars --fetch` for broader coverage (`snitch:backfill-covers --fetch` for covers only). Sync archives a cover on create, and again for an existing post when the stored cover is not already a local file or a YouTube thumb. Explore calls `PostCoverHydrator::ensureMirrored` for untracked corpus posts.
- Keep thumbnail/`media_url` fallback visible so 3/4 contact frames and polaroids stay filled.
- Never put `!aspect-auto` on `.snitch-polaroid-frame` around `PlatformEmbed`. The still is `position: absolute`, so a frame without 3/4 height collapses to zero.
- `embedLoadQueue.ts` stays for any leftover iframe experiments. Do not wire it back into list views. The post page loads its single player directly.
- Contact-cell frame CSS (`aspect-ratio: 3/4`) must stay so covers do not collapse layout.
- Instagram sync imports stills and carousels as well as reels. Feed and Snitch Show list every imported type. AnalyzePostJob also reads carousels, image posts, and text posts. Explore stays reel-like.
- Proof sheets use `.snitch-contact-sheet-proof` (`auto-fill` 8.5-10.75rem cards) unless the board should span the canvas.
- Feed and Explore use `.snitch-contact-sheet-proof-fill` (`auto-fit` + `1fr`, min 12rem) so leftover canvas is not a right gutter. Keep 3/4 frames. Do not add `grid-cols-*` on those boards. Dashboard Latest posts is a compact 6-thumb row (not the tall cream contact sheet) plus Open feed - full boards stay on `/feed`. Account recent posts keep `.snitch-contact-sheet-rows` and also pass `compact`.
- Snitch Show recent posts use `.snitch-contact-sheet-rows` (`--snitch-sheet-cols` = ceil(count / 2), capped at 6) so the sheet aims for two rows. Each column maxes at 14rem and the board hugs those columns, so a short row does not stretch into posters.
- `FeedContactCell` resolves the network slug from `post.platform`, then `tracked_account.platform`, then `social_account.platform`. Explore must call `PostAccountPresenter::attachForUser` *after* any `$post->refresh()` (cover mirror) so dynamic attrs are not wiped, and `normalizePlatform` must fill a real slug for every card.
- On the post page the creator `@handle` links to the viewer's tracking page when they track that account. Otherwise it opens the social profile URL (`tracked_account.url`) in a new tab.
