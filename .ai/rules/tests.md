# Tests

## Live vetting test-brand fallback
Prefer GrantGunner when rivals post recent public reels. If that niche is quiet/unresolvable, switch BrandProfile to a high-activity creator niche (PewDiePie or equivalent), confirm 2-4 active competitors, then sync/analyze/winners on last-month posts only. Do not burn budget on deep history.

## YouTube live smoke prefers Shorts-active channels
For YouTube Shorts live probes, prefer channels that post Shorts inside the recency window (e.g. MrBeast). PewDiePie may resolve a profile but return zero Shorts recently - that is empty data, not an adapter failure.
